LEARNING GUIDE

How to Use This Simulation

1. Choose a scheduling algorithm: FCFS, Rate Monotonic, or EDF.
2. Press Play to start the ICU CPU simulation.
3. Watch which sensor task receives CPU time.
4. Observe whether any task misses its deadline.
5. Reset and compare the algorithms to understand how scheduling decisions affect time-critical medical monitoring.

How AI Was Used

AI was used as a creative and development assistant.

💡 KEY TAKEAWAY

Correct + On Time = Safe

In a real-time medical system, producing the correct result is not always enough. Critical tasks must also complete before their deadlines.

A delayed critical response can be as dangerous as an incorrect one.
